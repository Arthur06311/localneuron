# LocalNeuron 0.10 — interface

A interface passa a usar superfícies neutras, tipografia de sistema, ícones SVG locais e controles com dimensões consistentes. Os temas claro, escuro e automático continuam salvos no dispositivo. O ícone C foi preservado.

- Navegação lateral estável entre Chat, Modelos, Estúdio, API e Preferências; navegação horizontal em telas pequenas.
- Chat com leitura centralizada, editor destacado e acesso direto à voz, ferramentas, internet e esforço.
- Biblioteca com busca, filtros, favoritos, comparação, requisitos de memória e download; instruções de instalação em uma seção recolhível.
- Painéis de configuração, API, criação e desbloqueio seguem a mesma tipografia, contraste e espaçamento.
- Navegar entre páginas volta ao topo. O histórico do chat mantém a lista vertical em telas menores.
- Sem fontes externas, CDN ou dependências novas; o visual funciona offline.

O redesenho não altera a qualidade dos modelos, os motores, as licenças nem os requisitos de hardware. O catálogo mantém 579 modelos de texto e seis modelos auxiliares. Compatibilidade e limitações continuam descritas na interface.
