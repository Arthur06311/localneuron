# Site do LocalNeuron

O site público tem uma única fonte: a branch [`gh-pages`](https://github.com/Arthur06311/localneuron/tree/gh-pages), publicada em [localneuron.ai](https://localneuron.ai).

Esta pasta, em `main`, está vazia de propósito. Não acrescente HTML, CSS, JavaScript, imagens nem o catálogo de downloads aqui.

## Como propor uma mudança

Abra um pull request **contra a branch `gh-pages`**, e não contra `main`.

1. Crie um branch a partir de `gh-pages`.
2. Faça a alteração do site nesse branch.
3. Na abertura do pull request, escolha `gh-pages` como base.

Esta pasta não é publicada.
