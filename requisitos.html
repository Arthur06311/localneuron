Requisitos do sistema

LocalNeuron 0.28.1 está em alfa. O aplicativo é para macOS Apple Silicon, Windows x64 e Linux x64. O Mac foi validado com download e inferência reais. No Windows e no Linux, a validação nativa dos motores ainda está pendente. Mac Intel não é compatível.

Os modelos não vêm no pacote. O download de cada um ocupa disco à parte. A ficha na biblioteca mostra o tamanho e a RAM estimada antes de baixar.

macOS

ItemRequisito
ProcessadorApple Silicon. Mac Intel não é compatível.
macOS mínimomacOS 14 ou mais recente para o motor MLX. Imagem e vídeo no Mac pedem macOS 26 ou mais recente. O nó EXO gerenciado pede macOS 26.2 ou mais recente.
PacoteLocalNeuron-macOS-arm64.dmg. Arraste para Aplicativos.

A execução desta alfa foi verificada no macOS 26.6.2. Motores no Mac: llama.cpp com Metal, MLX e whisper.cpp. O binário visual pede macOS 26+.

Windows

ItemRequisito
SistemaWindows x64.
PacoteLocalNeuron-Windows-x64-Setup.exe. Execute o instalador.
MotoresOs pacotes incluídos rodam em CPU. A validação nativa ainda está pendente.
  • Os motores podem precisar do Microsoft Visual C++ Redistributable x64.
  • O Editor pede Python 3 instalado no sistema.
  • No Windows, a Rede EXO só controla um EXO de outro computador. Não há nó nativo.

Linux

ItemRequisito
SistemaLinux x64 com glibc e sessão gráfica Wayland ou X11.
PacotesDEB para Ubuntu e Debian, AppImage, e pacote Arch com sudo pacman -U.
MotoresOs pacotes incluídos rodam em CPU. A validação nativa ainda está pendente.
  • DEB: LocalNeuron-Linux-x64.deb. O teste nativo documentado usa Ubuntu 24.04.
  • AppImage: LocalNeuron-Linux-x64.AppImage. Marque como executável e abra.
  • Arch e Omarchy: sudo pacman -U no pacote publicado. Não extraia o arquivo à mão.

Disco dos modelos

O tamanho do aplicativo não inclui os modelos. Cada modelo é baixado na biblioteca, e a ficha mostra o tamanho antes do download.

Música (ACE-Step 1.5) é instalação separada: 25 GiB livres para preparar o ambiente. Os pesos e as dependências ocupam cerca de 5,89 GiB (6,32 GB na ficha). A geração real foi verificada no Mac Apple Silicon.
